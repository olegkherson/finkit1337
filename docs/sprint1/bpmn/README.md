# Моделі бізнес-процесів


## Склад моделей

### 1. Переказ коштів (`01_transfer.drawio`)
- Специфікація: `product.md`, розділ 3.1
- Пули: Клієнт, Банк (Система, Операціоніст), Процесинговий центр
- Ключова логіка: паралельний шлюз (AND) для атомарного дебетування та кредитування, перевірка добового ліміту 50 000 грн з ескалацією на ручну обробку.

### 2. Оформлення кредиту (`02_loan.drawio`)
- Специфікація: `product.md`, розділ 3.2
- Пули: Клієнт, Банк (Система, Ризик-менеджер, Операціоніст)
- Ключова логіка: розгорнутий підпроцес скорингу (УБКІ, DTI, бал), ручний розгляд заявок понад 400 000 грн, шлюз за подіями з очікуванням підписання до 7 днів.

### 3. Відкриття рахунку (`03_account.drawio`)
- Специфікація: `product.md`, розділ 3.3
- Пули: Клієнт, Банк (Система, Операціоніст)
- Ключова логіка: KYC-верифікація нових клієнтів операціоністом, розділені шлюзи злиття ідентифікації та перевірки внеску, валідація суми первинного внеску.

### 4. Оплата рахунку (`04_payment.drawio`)
- Специфікація: `product.md`, розділ 3.4
- Пули: Клієнт, Банк (Система), Одержувач платежу
- Ключова логіка: автоматичний розрахунок комісії банку, валідація формату IBAN, передача платіжного доручення одержувачу.

## Правила нотації BPMN 2.0

- Sequence Flow (суцільна стрілка) - виключно внутрішні переходи в межах одного пулу.
- Message Flow (пунктирна стрілка) - взаємодія між різними пулами.
- Gateways - усі шлюзи розгалуження мають чітко підписані умови виходу та коректні вузли злиття.
- Data Objects / Stores - відображають документообіг (реквізити, квитанції) та сховище рахунків.
